# Track-a-Taxi

A data science project analysing NYC yellow taxi demand patterns and their relationship with weather conditions, with the goal of building a predictive model for hourly zone-level demand.

**Course:** COMS30050 Applied Data Science — University of Bristol

---

## Project Overview

Using NYC Taxi & Limousine Commission (TLC) trip record data merged with NOAA weather observations, this project investigates:

- How weather (rain, temperature, wind, visibility) correlates with yellow taxi demand
- How demand varies by time of day, day of week, and season
- Which NYC zones drive the most taxi activity
- Whether hourly demand can be predicted from weather and temporal features

The dataset covers **2022–2025**, at **hourly granularity**, across all **263 NYC taxi zones**.

## Dataset

The core dataset is a pre-merged parquet file combining:

| Source | Description |
|--------|-------------|
| [NYC TLC Trip Records](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) | Yellow taxi pickups, hourly aggregated by zone |
| [NOAA Weather Data](https://www.ncdc.noaa.gov/) | Hourly observations from Central Park, JFK, and LaGuardia |

**Key columns:**

| Column | Description |
|--------|-------------|
| `PULocationID` | NYC taxi zone (1–263) |
| `pickup_hour` | Timestamp (hourly) |
| `trip_count` | Target variable — taxi pickups in that zone-hour |
| `precipitation` | Hourly precipitation |
| `temperature` | Temperature (°C) |
| `wind_speed` | Wind speed |
| `visibility` | Visibility |
| `rain_category` | Categorical rain intensity (0 = none, 4 = heavy) |
| `lag_1/2/24/168` | Demand 1hr, 2hr, 24hr, and 1 week prior (same zone) |
| `hour`, `day_of_week`, `is_weekend`, `is_rush_hour` | Engineered time features |

> Data files are not included in this repo due to size. The exploration script expects the raw zip files in `OneDrive_1_27-03-2026/`.

## Key Findings (EDA)

- **9.2M rows** across 4 years, 263 zones
- **~60% of zone-hours have zero demand** — the dataset is sparse; most activity is concentrated in central Manhattan zones
- **Strong temporal patterns:** demand peaks around 18:00–19:00, is higher on weekdays, and dips in winter months
- **Lag features are the strongest predictors** of demand (r > 0.9 for lag_1), confirming high temporal autocorrelation
- **Weather correlations are modest but present** — rain shows a small positive correlation with demand; temperature shows a moderate positive correlation
- **Data quality note:** precipitation values appear to be recorded in mm but labelled as inches — this needs correcting before modelling. ~9.5% of weather readings are flagged as imputed (`was_missing=True`), concentrated in Q4 2025.

## Getting Started

### Requirements

```
pandas
numpy
matplotlib
seaborn
fastparquet
```

Install with:

```bash
pip install pandas numpy matplotlib seaborn fastparquet
```

### Run the exploration

```bash
python exploration/data_exploration.py
```

The script will extract the parquet (first run only), print findings to the console, and save all plots to `data/`.
